## 📌 ¿Qué es CDPN?

**CyberDefense Pro Network** es una plataforma de formación profesional en ciberseguridad diseñada para:

- 🎯 **Profesionales** que buscan certificaciones (OSCP, CEH, CISSP)
- 🎓 **Estudiantes** que quieren especializarse en seguridad
- 🏢 **Equipos SOC/Red Team** que necesitan capacitación práctica
- 🌎 **Hispanohablantes** que buscan contenido técnico de calidad

> *"No coleccionamos diapositivas, coleccionamos profesionales capacitados."*
