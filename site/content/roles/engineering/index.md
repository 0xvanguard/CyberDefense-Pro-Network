# 🔧 Engineering / Ingeniería de Seguridad

Roles especializados en construcción y arquitectura de seguridad.

| Role | Especialización |
|------|-----------------|
| [🔧 Security Engineer](/roles/engineering/security-engineer/) | Ingeniería de seguridad, automación |
| [💼 Security Consultant](/roles/engineering/security-consultant/) | Consultoría, auditorías, compliance |
| [🏛️ Arquitecto de Seguridad](/roles/engineering/arquitecto-seguridad/) | Diseño de arquitecturas seguras |
| [☁️ Cloud Security](/roles/engineering/seguridad-nube/) | AWS, Azure, GCP, container security |
| [🧱 AppSec](/roles/engineering/seguridad-aplicaciones/) | Secure coding, SAST/DAST, OWASP |
| [🏭 IoT/OT Security](/roles/engineering/seguridad-iot-ot/) | Seguridad industrial, SCADA, IoT |
| [🔐 Data Security](/roles/engineering/seguridad-informacion-datos/) | Protección de datos, cifrado |
| [📦 Supply Chain](/roles/engineering/seguridad-cadena-suministro/) | SBOM, dependencias, CI/CD |
| [🤖 AI Security](/roles/engineering/ia-security/) | Seguridad de modelos IA, LLM |
| [📋 GRC/Compliance](/roles/engineering/grc-compliance/) | Gobernanza, riesgo, cumplimiento |
