## 🚀 Cómo empezar

1. **Elige un lab** de tu nivel
2. **Abre la terminal** del lab interactivo
3. **Sigue las instrucciones** y resuelve cada ejercicio
4. **Captura las flags** para ganar XP
5. **Desbloquea badges** con logros especiales

::: tip Progreso
Tu progreso se guarda localmente en el navegador. Completa todos los labs de un nivel para desbloquear el siguiente.
:::
