## 🔄 Cómo Funciona la Sincronización

```
📝 Editas en la web (admin.html) o en GitHub
        ↓
   GitHub recibe el commit
        ↓
   GitHub Actions construye el sitio
        ↓
   🌐 Campus se actualiza automáticamente
```
