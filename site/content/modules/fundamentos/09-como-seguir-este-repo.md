# 09 — Cómo seguir este repo a partir de aquí

> 🎯 **Objetivo:** una vez leída la base, saber qué carpeta abrir según lo que te interese o lo que necesites profundizar. Este archivo es tu mapa.

## ¿Qué has hecho ya?

Si vienes de los archivos anteriores de esta carpeta, ya tienes:
- ✅ Idea general del campo y los roles
- ✅ Glosario para no perderte con la jerga
- ✅ Conceptos de redes
- ✅ Manejo básico de Linux y Windows
- ✅ Criptografía fundamental
- ✅ Cómo se clasifican las vulnerabilidades
- ✅ Ética y marco legal
- ✅ Lista de herramientas clave

Ya puedes leer cualquier parte del repo sin sentirte perdido.

## 🔀 ¿Qué te interesa?

Elige una de las 4 rutas siguientes y abre su archivo:

### 🛡️ Si te gusta defender
→ [`rutas/ruta-defensor.md`](./rutas/ruta-defensor.md)

Quiero entender al atacante para defender mejor:
→ [`rutas/ruta-atacante.md`](./rutas/ruta-atacante.md)

### 🤖 Si te interesa la IA
→ [`rutas/ruta-ai-security.md`](./rutas/ruta-ai-security.md)

### 🧪 Si quieres practicar primero
→ Salta directamente a [`../04-LABORATORIOS/`](../04-LABORATORIOS/)

## 🤝 Contribuir

Encontraste un error en la base?¿Falta algo?¿Quieres mejorar un archivo?

- Abre un issue describiendo el cambio.
- O manda un PR directamente.
- También mira [`../CONTRIBUIR.md`](../CONTRIBUIR.md) y [`../TEMPLATE-MODULO.md`](../TEMPLATE-MODULO.md).

## 🗺️ ¿Y el sitio web publicado?

Hay un sitio en GitHub Pages montado con todo este contenido, en [`../docs/`](../docs/). Allí encontrarás:
- `index.html` — landing
- `app.html` — aplicación
- `herramientas.html`, `recursos.html`, `labs.html`, `retos.html`
- `modules/` — los mismos módulos del repo raíz, navegables como web

Cuando un PR mergea, el sitio se regenera automáticamente.

## ✏️ Ejercicio final

1. Cierra esta carpeta.
2. Elige una ruta en [`./rutas/`](./).
3. Lee su archivo completo y abre las carpetas que te sugiere.
4. Programa al menos 1 hora para practicar en un lab esa semana.
