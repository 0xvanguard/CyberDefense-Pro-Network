Ruta de Aprendizaje Recomendada

Sigue esta ruta para construir una carrera sólida en ciberseguridad.

1

Fundamentos (Mes 1-2)

  • Aprende Linux básico (OverTheWire Bandit)
  • Redes: TCP/IP, DNS, HTTP (CompTIA Network+)
  • Terminal y comandos básicos
  • Primeras prácticas en TryHackMe
2

Seguridad Básica (Mes 3-4)

  • CompTIA Security+ (estudiar + certificar)
  • eJPT (examen práctico)
  • Conceptos: CIA, autenticación, criptografía
  • Herramientas: Nmap, Burp Suite básico
3

Especialización (Mes 5-8)

  • Elige: Ofensiva (PEN-200) o Defensiva (CySA+)
  • Máquinas HTB y THM regularmente
  • Writeups detallados de cada máquina
  • Participa en CTFs
4

Profesional (Mes 9-12)

  • OSCP o CySA+ certificación
  • Proyectos personales en GitHub
  • Blog o portfolio de writeups
  • Networking con la comunidad
5

Avanzado (Año 2+)

  • OSCE, OSEP u otras avanzadas
  • Contribuciones open source
  • Mentoría y enseñanza
  • Especialización profunda

Cheatsheets Esenciales

Referencias rápidas que deberías tener siempre a mano.

Linux Commands

# Navegación
pwd, ls -la, cd, find, locate

# Archivos
cp, mv, rm, mkdir, touch, cat, nano

# Procesos
ps aux, top, kill, bg, fg

# Red
ip a, ss -tlnp, ping, curl, wget

# Permisos
chmod 777, chown, chgrp

# Búsqueda
grep -r "pattern", find / -name "*.txt"

Nmap

# Básico
nmap target

# Completo
nmap -sV -sC -O -p- target

# Stealth
nmap -sS -T2 -Pn target

# Scripts
nmap --script=vuln target

# Output
nmap -oA result target

Best Practices por Área

Guías de mejores prácticas profesionales que debes conocer.

Red Team

  • Siempre ten autorización por escrito
  • Documenta cada paso y hallazgo
  • Reporta hallazgos críticos de inmediato
  • Respeta el alcance definido
  • Incluye lecciones defensivas en tu reporte

Blue Team

  • Mantén logs centralizados (SIEM)
  • Implementa MFA en todo
  • Actualiza y parchea regularmente
  • Segmenta tu red
  • Ejecuta tabletop exercises

Cloud Security

  • Nunca hardcodear credenciales
  • Usar IAM least privilege
  • Habilitar CloudTrail/audit logs
  • Usar Vault para secrets
  • Escanear IaC antes de deployar

DevSecOps

  • SAST en el pipeline CI/CD
  • SCA para dependencias
  • Container scanning
  • Secrets scanning en repos
  • Infrastructure as Code scanning
