8. 🎙️ VOZ — Sé respetuoso en canales de voz

## 🎯 Sistema de XP y Niveles

### Cómo Ganar XP
| Acción | XP |
|--------|-----|
| Mensaje en chat | +10 XP |
| Reacción recibida | +5 XP |
| Compartir writeup | +100 XP |
| Ayudar en #dudas | +50 XP |
| Completar lab | +200 XP |
| Asistir a evento | +150 XP |

### Niveles y Beneficios
| Nivel | XP Requerido | Beneficio |
|-------|--------------|-----------|
| 🌱 1 | 0 | Acceso básico |
| 🥉 5 | 500 | Acceso a #recursos |
| 🥈 10 | 2,000 | Acceso a #writeups |
| 🥇 20 | 5,000 | Acceso a #proyectos |
| 💎 30 | 10,000 | Acceso a mentoría |
| 🌟 50 | 25,000 | Rol legendario |
