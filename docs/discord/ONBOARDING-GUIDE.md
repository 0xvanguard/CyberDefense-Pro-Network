# 👋 Guía de Onboarding — Discord CDPN

> Bienvenido a la comunidad de CyberDefense Pro Network. Esta guía te ayudará a empezar.

---

## 🎯 Paso 1: Preséntate

Ve a `#introduccion` y cuéntanos:

```markdown
👋 **Nombre:** [Tu nombre]
🎯 **Nivel:** Principiante / Intermedio / Avanzado
🔴 **Interés:** Red Team / Blue Team / Purple Team / AI Security
💼 **Experiencia:** [Breve descripción]
🎯 **Objetivo:** [Qué quieres lograr]
```

**Ejemplo:**
```markdown
👋 **Nombre:** Carlos
🎯 **Nivel:** Principiante
🔴 **Interés:** Red Team
💼 **Experiencia:** Estudiante de ingeniería, 0 experiencia en seguridad
🎯 **Objetivo:** Conseguir mi primer empleo en pentesting
```

---

## 🎭 Paso 2: Asigna tus Roles

Ve a `#roles` y haz clic en las reacciones para obtener:

### Roles de Especialización
- 🔴 **Red Team** — Si te interesa el pentesting
- 🔵 **Blue Team** — Si te interesa la defensa
- 🟣 **Purple Team** — Si te interesa la colaboración
- 🤖 **AI Security** — Si te interesa la IA
- 🔧 **DevSecOps** — Si te interesa seguridad en DevOps
- ☁️ **Cloud Security** — Si te interesa cloud

### Roles de Certificación
- 🏅 **OSCP** — Si tienes esta certificación
- 🏅 **eJPT** — Si tienes esta certificación
- 🏅 **CEH** — Si tienes esta certificación

## 🎓 Paso 4: Únete a un Study Group

### Grupos Disponibles
- **HTB Group** — Viernes 19:00
- **THM Group** — Miércoles 19:00
- **CTF Group** — Sábados 20:00

### Cómo Participar
1. Ve a `#retos` para ver el reto semanal
2. Únete al canal de voz `#estudio-grupo`
3. Trabaja en el reto con otros miembros
4. Comparte tu solución en `#writeups`

## 🏆 Paso 5: Gana XP

### Cómo Ganar XP
| Acción | XP |
|--------|-----|
| Mensaje en chat | +10 XP |
| Ayudar a otros | +50 XP |
| Compartir writeup | +100 XP |
| Completar lab | +200 XP |
| Asistir a evento | +150 XP |

### Niveles
- 🌱 **Nivel 1:** 0 XP — Acceso básico
- 🥉 **Nivel 5:** 500 XP — Acceso a #recursos
- 🥈 **Nivel 10:** 2,000 XP — Acceso a #writeups
- 🥇 **Nivel 20:** 5,000 XP — Acceso a #proyectos
- 💎 **Nivel 30:** 10,000 XP — Mentoría
- 🌟 **Nivel 50:** 25,000 XP — Legendario

## 🤝 Paso 7: Contribuye

1. **Comparte knowledge** — Escribe en los canales

### ¿Hay mentoría?
Sí, para miembros nivel 30+. Pide en `#mentoría`.

### ¿Puedo crear eventos?
Sí, contacta a un admin con tu propuesta.
