Inicio Rápido

Levanta cualquier lab en menos de 2 minutos.

Terminal
# 1. Clonar el repositorio
git clone https://github.com/0xvanguard/CyberDefense-Pro-Network.git
cd CyberDefense-Pro-Network

# 2. Navegar al lab deseado
cd labs/intermedio/pentest-01  # Ejemplo: Pentesting

# 3. Levantar el entorno
docker compose up -d

# 4. Verificar servicios
docker compose ps

# 5. Obtener shell en el contenedor atacante
docker compose exec kali bash

# 6. ¡A practicar!
# Sigue las instrucciones del README.md

# 7. Validar progreso
./scripts/validate.sh

# 8. Detener el lab
docker compose down
