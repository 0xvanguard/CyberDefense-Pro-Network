03 — Análisis de Vulnerabilidades

Identificar, priorizar y comunicar vulnerabilidades con CVSS, CIA y gestión de vulnerabilidades.

Objetivos de Aprendizaje

Diferenciar hallazgo, debilidad, vulnerabilidad, riesgo e impacto.
Clasificar hallazgos usando la tríada CIA.
Aplicar el ciclo de vulnerability management.
Usar Nuclei, OpenVAS y searchsploit para obtener evidencia.

Contenido del Módulo

01

Tríada CIA y Severidad

Fundamentos

Clasificar vulnerabilidades por impacto en Confidencialidad, Integridad y Disponibilidad.

1
Confidencialidad: Acceso no autorizado a datos
2
Integridad: Modificación no autorizada de datos
3
Disponibilidad: Pérdida de acceso a servicios
CVSS
# CVSS v3.1 Score Calculator
# https://www.first.org/cvss/calculator/3.1

# Ejemplo: SQL Injection
# AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H = 9.8 (CRÍTICA)

# Severidad:
# 0.0 - 3.9  → BAJA
# 4.0 - 6.9  → MEDIA
# 7.0 - 8.9  → ALTA
# 9.0 - 10.0 → CRÍTICA
02

Ciclo de Gestión de Vulnerabilidades

Vulnerability Management

Descubrir, priorizar, remediar, validar y reportar.

1
Descubrir: Escaneo con Nuclei, OpenVAS, Nmap
2
Priorizar: CVSS + impacto business
3
Remediar: Parches, configuración, compensación
4
Validar: Re-escaneo y verificación
5
Reportar: Documentación profesional
03

Perspectiva Red/Blue/Purple

Trabajo en equipo

Un mismo hallazgo desde tres perspectivas diferentes.

🔴
Red Team: ¿Se puede explotar de forma realista?
🔵
Blue Team: ¿Qué activos afecta y cómo lo detecto?
🟣
Purple Team: ¿Cómo convertimos esto en mejora medible?
