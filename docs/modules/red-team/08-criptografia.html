08 — Criptografía

Cifrado, hashing, firmas digitales, criptoanalisis y PKI.

Objetivos de Aprendizaje

Dominar cifrado simétrico (AES, ChaCha20) y sus modos de operación.
Comprender cifrado asimétrico (RSA, ECC, Diffie-Hellman).
Aplicar hashing seguro (SHA-256, Argon2, bcrypt).
Detectar y explotar implementaciones débiles (ECB, padding oracle).

Contenido del Módulo

01

Cifrado Simétrico

AES, ChaCha20

Misma clave para cifrar y descifrar. Rápido pero requiere distribución segura.

1
AES: Estándar actual (128/192/256 bits)
2
ChaCha20: Alternativa moderna (TLS 1.3, WireGuard)
3
GCM: Modo autenticado (recomendado)
4
ECB: ❌ NUNCA usar (patrones visibles)
OpenSSL
# AES-256-GCM (recomendado)
openssl enc -aes-256-gcm -in secreto.txt -out secreto.enc -k "password123"

# Descifrar
openssl enc -aes-256-gcm -d -in secreto.enc -out secreto.txt -k "password123"
02

Cifrado Asimétrico

RSA, ECC, DH

Dos claves relacionadas: pública (cifrar) y privada (descifrar).

1
RSA: Basado en factorización de primos (≥2048 bits)
2
ECC: Misma seguridad con claves más pequeñas
3
Diffie-Hellman: Intercambio de claves por canal inseguro
4
ECDHE: Perfect Forward Secrecy en TLS 1.3
Python
# Generar claves RSA
from Crypto.PublicKey import RSA
key = RSA.generate(2048)

# Cifrar
from Crypto.Cipher import PKCS1_OAEP
cipher = PKCS1_OAEP.new(key.publickey())
ciphertext = cipher.encrypt(b"Secret message")
03

Hashing y Firmas Digitales

SHA-256, Argon2, PKI

Integridad de datos, autenticación y no repudio.

1
SHA-256: Hash estándar para integridad
2
Argon2: Hashing seguro de contraseñas
3
HMAC: Autenticación de mensajes
4
Firmas RSA/ECDSA: No repudio
5
PKI: Certificados y cadena de confianza
Bash
# SHA-256 de archivo
sha256sum archivo.zip

# HMAC-SHA256
echo -n "message" | openssl dgst -sha256 -hmac "secret_key"

# Firmar
openssl dgst -sha256 -sign private.pem -out firma.sig archivo.txt
04

Criptoanalisis

ATAQUES

Encontrar debilidades en implementaciones criptográficas.

1
ECB Pattern: Bloques idénticos → ciphertext idéntico
2
Padding Oracle: Descifrar sin clave observando padding
3
XOR: Análisis de frecuencia en cifrados débiles
4
Timing Attack: Deducir clave por tiempos de ejecución
hashcat John the Ripper CyberChef
05

Criptografía Post-Cuántica

Futuro

Algoritmos resistentes a computadoras cuánticas.

1
Shor: Rompe RSA, DH y ECC en tiempo polinómico
2
Grover: Reduce seguridad de hashes a la mitad
3
Kyber: Key encapsulation post-cuántico (NIST)
4
Dilithium: Firmas post-cuánticas (NIST)
