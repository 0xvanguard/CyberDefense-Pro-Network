06 — Forense Digital

Reconstruir qué pasó en un sistema con evidencia íntegra y admisible.

Objetivos de Aprendizaje

Establecer y mantener la cadena de custodia con hashing y documentación.
Crear imágenes bit a bit de discos y memoria RAM.
Analizar artefactos de Windows (Prefetch, Registry, $MFT).
Extraer procesos, conexiones y credenciales de volcados de RAM.
Construir una línea de tiempo unificada de eventos.

Contenido del Módulo

01

Cadena de Custodia y Adquisición

NIST SP 800-86

Principios fundamentales de preservación de evidencia digital.

1
No alterar: Nunca trabajes sobre el original
2
Cadena de custodia: Documentar quién, qué, cuándo
3
Reproducibilidad: Otro forense debe poder repetir tu proceso
4
Orden de volatilidad: Capturar lo más volátil primero
Adquisición
# Crear imagen bit a bit con hashing
dc3dd if=/dev/sda of=/evidencia/img.dd hash=sha256 log=hash.log

# Verificar integridad
sha256sum /dev/sda
sha256sum /evidencia/img.dd
# Deben coincidir
dc3dd FTK Imager avml
02

Análisis de Disco

NTFS, EXT4, APFS

Sistemas de archivos, artefactos de Windows y recuperación de datos.

1
$MFT: Master File Table — cada archivo registrado
2
$UsnJrnl: Historial de cambios en archivos
3
Prefetch: Programas ejecutados
4
Registry: Configuración y actividad de usuario
The Sleuth Kit
# Ver particiones
mmls imagen.dd

# Listar archivos
fls -r -o 2048 imagen.dd

# Listar archivos borrados
fls -d -r -o 2048 imagen.dd

# Extraer archivo por inode
icat -o 2048 imagen.dd 12345 > recuperado.pdf
The Sleuth Kit Autopsy Eric Zimmerman Tools
03

Análisis de Memoria

Volatility 3

Extraer evidencia de volcados de memoria RAM.

1
Procesos: pslist, pstree — detectar procesos ocultos
2
Red: netscan — conexiones activas
3
Código: malfind — inyecciones de código
4
Credenciales: hashdump — hashes NTLM
Volatility 3
# Información del sistema
vol -f memory.raw windows.info

# Lista de procesos
vol -f memory.raw windows.pslist

# Conexiones de red
vol -f memory.raw windows.netscan

# Código inyectado
vol -f memory.raw windows.malfind
Volatility 3 LiME winpmem

05

Timeline y Reporte

plaso, MFTECmd

Construir línea de tiempo unificada y documentar hallazgos.

1
plaso: Super timeline desde múltiples fuentes
2
Correlación: Conectar eventos de diferentes fuentes
3
Reporte: Documentar hallazgos profesionalmente
plaso
# Crear super timeline
log2timeline.py --storage-file timeline.plaso imagen.dd

# Filtrar por fecha
psort.py -o l2tcsv -w timeline.csv \
    timeline.plaso "date > '2026-08-20 00:00:00'"
