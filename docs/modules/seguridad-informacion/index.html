Guia: Evaluacion de Riesgos

1
Inventario: Servidores, BD, codigo, datos.
2
Amenazas: Hackers, desastres, fallos, insiders.
3
Controles: Firewall, antivirus, MFA.
4
Calcular: Prob(1-5) x Impacto(1-5) = Riesgo.
5
Tratar: Mitigar, Transferir, Aceptar, Evitar.
Python - Matriz
def riesgo(activo, amenaza, prob, imp):
    r = prob * imp
    n = "CRITICO" if r>=20 else "ALTO" if r>=12 else "MEDIO" if r>=6 else "BAJO"
    return f"[{n}] {activo}: {amenaza} (Riesgo: {r}/25)"

print(riesgo("BD clientes", "SQLi", 4, 5))
print(riesgo("Servidor web", "DDoS", 3, 4))
print(riesgo("Laptops", "Perdida fisica", 2, 3))

Guia: Politica de Contrasenas

1
12+ caracteres, mayuscula, digito, especial.
2
MFA obligatorio en todos los sistemas.
3
Caducidad 90 dias, historial 12 contrasenas.
4
Bloqueo tras 5 intentos fallidos.
Bash
sudo sed -i 's/^PASS_MAX_DAYS.*/PASS_MAX_DAYS   90/' /etc/login.defs
sudo apt install -y libpam-pwquality
cat > /etc/security/pwquality.conf << 'EOF'
minlen = 12
dcredit = -1
ucredit = -1
lcredit = -1
ocredit = -1
maxrepeat = 3
EOF

Guia: Hardening Linux

1
apt update && apt upgrade -y
2
Firewall UFW: solo 22, 80, 443
3
SSH: PermitRootLogin no, solo keys
4
Deshabilitar: avahi, cups, bluetooth
5
Auditoria: lynis audit system --quick
hardening.sh
#!/bin/bash
apt update && apt upgrade -y
apt install -y ufw lynis
ufw default deny incoming
ufw allow 22/tcp
ufw --force enable
cat >> /etc/ssh/sshd_config << 'SSH'
PermitRootLogin no
PasswordAuthentication no
SSH
systemctl restart sshd
lynis audit system --quick
