09 — Cómo seguir este repo

Ya tienes la base. Elige una ruta y salta a las carpetas específicas del repo.

¿Qué has hecho ya?

Si vienes de los archivos anteriores de esta carpeta, ya tienes:

  • ✅ Idea general del campo y los roles
  • ✅ Glosario para no perderte con la jerga
  • ✅ Conceptos de redes
  • ✅ Manejo básico de Linux y Windows
  • ✅ Criptografía fundamental
  • ✅ Cómo se clasifican las vulnerabilidades
  • ✅ Ética y marco legal
  • ✅ Lista de herramientas clave

Ya puedes leer cualquier parte del repo sin sentirte perdido.

¿Qué te interesa?

Elige una de las 3 rutas siguientes y abre su archivo:

🛡️

Defender sistemas

Blue Team, SOC, threat hunting, IR.

 ⚔️

Atacar y entender al atacante

Red Team, pentesting, bug bounty. Con ética firme.

 🤖

Seguridad de IA

Prompt injection, LLMs seguros, AI Red Teaming.

 🧪

Practicar primero

Salta a Labs.

¿Encontraste un error? ¿Falta algo? ¿Quieres mejorar un archivo?

  • Abre un issue describiendo el cambio.
  • O manda un PR directamente.

Este repo mejora cuando la comunidad lo toca.

Ejercicio final

  1. Cierra esta carpeta.
  2. Elige una ruta en rutas/.
  3. Lee su archivo completo y abre las carpetas que te sugiere.
  4. Programa al menos 1 hora para practicar en un lab esa semana.
Recordatorio final

La base no se aprende de una vez. Vuelve aquí cada vez que un módulo te deje con dudas. La repetición espaciada funciona.
