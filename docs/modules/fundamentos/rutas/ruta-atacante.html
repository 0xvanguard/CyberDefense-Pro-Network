⚔️ Ruta Atacante

Para gente curiosa por saber cómo se rompen las cosas. Con responsabilidad: ética primero, ley primero, siempre.

Mentalidad

"Si rompo esto aquí, ¿qué roto en producción? ¿Quién se entera? ¿Cómo se defiende?"

Antes de empezar, lee 07 — Ética y leyes. Si no estás cómodo con ese marco, esta ruta no es para ti.

Roles Red Team

  • Pentester — auditorías cortas (1-2 semanas).
  • Red Teamer — simulación prolongada de un adversary.
  • Bug Bounty Hunter — freelance, por recompensa.
  • Exploit Developer — escribe los exploits que otros usan.

Refuerza la base técnica

  • 03 — Internet y redes: TCP, HTTP, DNS, TLS.
  • 04 — SO y terminal: vive en la terminal.
  • Aprende algo de scripting: Python es obligatorio, Bash también.
  • Repasa 06 — Vulnerabilidades: OWASP, CVEs, CWE.

Las fases del pentest

  1. Pre-engagement — contrato, scope, reglas.
  2. Reconocimiento (pasivo / activo).
  3. Enumeración — servicios, versiones, users.
  4. Análisis de vulnerabilidades.
  5. Explotación.
  6. Post-explotación — pivot, persistencia.
  7. Reporte.

Las herramientas por fase:

nmap → masscan → rustscan
├── whatweb → Wappalyzer
├── gobuster → feroxbuster
├── Burp Suite / ZAP
├── Metasploit / searchsploit
├── LinPEAS / WinPEAS (priv esc)
└── BloodHound (Active Directory)

Reporte — la mitad del trabajo

El éxito de un pentest se mide por el reporte, no por los hallazgos.

Estructura recomendada:

  1. Resumen ejecutivo (1 página, sin jerga, para CISO).
  2. Metodología.
  3. Hallazgos (Título + severidad + CVE/CWE/CVSS, descripción, pasos, impacto, evidencia, recomendación).
  4. Conclusiones.

Templates disponibles en 02-pentesting-red-team/portafolio/.

Certificaciones sugeridas

  1. eJPT (eLearnSecurity Junior Penetration Tester) — primer paso accesible.
  2. CompTIA PenTest+ — base general.
  3. PNPT (Practical Network Penetration Tester) — práctico.
  4. OSCP — la referencia de facto en pentest.
  5. OSWE — si te enfocas en web.
  6. CRTO — si te enfocas en red team moderno.
  7. CRTP — Active Directory.

Plan de 30 días

  • Semana 1: Instala Kali o tira una VM Ubuntu. Aprende 5 comandos diarios. Termina 04 — SO.
  • Semana 2: Completa TryHackMe "Jr Penetration Tester" hasta la mitad. Lee 08 — Herramientas.
  • Semana 3: Resuelve 3 retos de PortSwigger Academy (XSS, SQLi, SSRF).
  • Semana 4: Abre 02-pentesting-red-team/ y haz el lab. Escribe tu primer mini-reporte.
