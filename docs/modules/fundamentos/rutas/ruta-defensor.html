🛡️ Ruta Defensor

Para gente que disfruta encontrar al malo, mirar logs, configurar detecciones y responder a incidentes.

Mentalidad

"Los atacantes tienen que acertar UNA vez. Yo tengo que acertar SIEMPRE."

Suena injusto, pero también significa que tu trabajo se nota cuando funciona (nada se rompe) y se nota MUCHO cuando no funciona. Por eso defender bien es difícil y se paga bien.

Roles Blue Team que existen

  • Analista SOC — vigila alertas 24/7.
  • Threat Hunter — busca atacantes ya dentro.
  • Incident Responder — actúa cuando algo se rompe.
  • Threat Intelligence Analyst — estudia quién atacaría y cómo.
  • Forense — investiga después de un incidente.
  • Malware Analyst — desarma software malicioso.

Aprende lo técnico defensivo

Redes

  • Aprende a leer PCAPs con Wireshark.
  • Entiende cómo se mueve lateralmente un atacante.

Logs

  • Conoce las ubicaciones de logs en Linux y los Event IDs clave en Windows.
  • Practica filtrar: grep, awk, jq, Splunk SPL.

Herramientas

  • Wazuh / OSSEC — HIDS.
  • Splunk / ELK — SIEM.
  • Velociraptor — endpoint DFIR.
  • MISP / OpenCTI — Threat Intel.

Aprende el marco MITRE

  • MITRE ATT&CK — cómo piensa y actúa un atacante.
  • MITRE D3FEND — técnicas defensivas para contrarrestar.
  • MITRE Caldera — emular atacantes en tu entorno.

Certificaciones sugeridas (opcional)

  1. BTL1 (Blue Team Level 1) — excelente para empezar.
  2. CompTIA Security+ — base general.
  3. SC-200 (Microsoft Security Operations Analyst) — Azure + Sentinel.
  4. GCIH (GIAC Certified Incident Handler) — respuesta a incidentes.
  5. GCFA (GIAC Certified Forensic Analyst) — forense.
  6. CISSP — cuando tengas experiencia.

Haz "home labs" reales

  • Monta un SIEM casero (ELK o Wazuh + VMs).
  • Levanta un endpoint y prueba detecciones.
  • Genera tráfico malicioso controlado y mira qué loggea.
  • Escribe detecciones propias y mide falsos positivos.

Plan de 30 días para empezar

  • Semana 1: Relee el glosario y abre 03-blue-team-defensa/.
  • Semana 2: Completa 2 labs de .../laboratorios/.
  • Semana 3: Monta Wazuh o ELK en tu VM y configura detección básica.
  • Semana 4: Lee todo lo de 02-blue-team-defensa/ y elige un área para profundizar.
Bonus

Si haces Red Team además de Blue Team, mira 04-purple-team-colaboracion/. El perfil completo Blue+Red es muy buscado.
