08 — Herramientas esenciales

Las 10-15 herramientas que verás 1000 veces. Todas gratuitas o con versión community.

Antes de instalar nada

  • Practica SIEMPRE en máquinas propias o en TryHackMe / HackTheBox.
  • Si vas a usar Kali, viene preinstalado: solo arranca y aprende.
  • Casi todas tienen versión Docker: docker run -it kalilinux/kali-rolling /bin/bash.
  • No mezcles herramientas de ataque con tu vida personal. Usa una VM dedicada.

Reconocimiento / OSINT

Nmap — el rey del escaneo de puertos

# Scan básico
nmap 192.168.1.1

# Rápido y sigiloso (SYN)
nmap -sS -T4 192.168.1.0/24

# Detección de versiones y OS
nmap -sV -O 192.168.1.1

# Scripts NSE (vulns, brute fuerza)
nmap --script=vuln 192.168.1.1

theHarvester / Amass / SpiderFoot

# theHarvester: emails, subdominios, hosts
theHarvester -d ejemplo.com -b all

# Amass: subdominios
amass enum -d ejemplo.com

Shodan / Censys: shodan.io — buscar dispositivos conectados en internet.

Análisis de tráfico

Wireshark

# CLI (tshark) en servers
sudo tshark -i eth0 -c 100     # captura 100 paquetes
sudo tshark -i eth0 -Y 'http'  # solo HTTP
sudo tshark -i eth0 -Y 'ip.addr == 1.2.3.4'

Trucos de filtro: http.request, dns.qry.name, tcp.flags.syn == 1 && tcp.flags.ack == 0.

tcpdump — clásico CLI

sudo tcpdump -i eth0 -w captura.pcap
sudo tcpdump -i eth0 'port 80'

Web — pentest y defensa

Burp Suite — el inspector web

  1. Configura tu navegador para usar Burp como proxy (127.0.0.1:8080).
  2. Instala el certificado CA de Burp para HTTPS.
  3. Navega como siempre — Burp captura y permite modificar.
  4. Replay con Repeater.

OWASP ZAP — alternativa open source

Similar a Burp pero open source.

Gobuster / dirsearch — fuerza bruta de directorios

gobuster dir -u https://ejemplo.com -w /usr/share/wordlists/dirb/common.txt

Nikto — escáner web

nikto -h https://ejemplo.com

Explotación

Metasploit Framework

# Inicia
msfconsole

# Busca un exploit
search type:exploit name:smb

# Usa un módulo
use exploit/windows/smb/ms17_010_eternalblue

# Configura y lanza
set RHOSTS 192.168.1.10
exploit

Solo en labs autorizados.

searchsploit — busca exploits localmente

searchsploit nginx 1.14

John the Ripper / hashcat — romper hashes

john --wordlist=/usr/share/wordlists/rockyou.txt hash.txt
hashcat -m 0 hash.txt rockyou.txt    # MD5
