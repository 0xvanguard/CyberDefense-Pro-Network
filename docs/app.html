¿Qué es la Ciberseguridad?

La ciberseguridad es la práctica de proteger sistemas, redes y programas de ataques digitales.

Tus Dispositivos

Computadora, celular, tablet

Tus Datos

Tu Primera Semana - Paso a Paso

Día 1-2: Preparar Entorno
  1. Descargar VirtualBox (gratis)
  2. Descargar Ubuntu Desktop
  3. Crear VM con 4GB RAM y 50GB disco
  4. Instalar Ubuntu en la VM
Día 3-4: Aprender Linux
pwdDirectorio actual
lsListar archivos
cdCambiar directorio
mkdirCrear carpeta
nanoEditar archivo
sudoModo admin
Día 5: Entender Redes
  • IP Address: Dirección de tu PC en la red
  • DNS: Traduce nombres a IPs
  • HTTP/HTTPS: Protocolos web
  • Puertos: Canales de comunicación (80=web, 22=SSH)
Día 6: Primer Escaneo con Nmap
sudo apt install nmap
nmap localhost
nmap scanme.nmap.org
Día 7: Explorar Plataformas
  • ✅ Crear cuenta en TryHackMe
  • ✅ Completar "Introduction to Cyber Security"
  • ✅ Explorar ruta "Pre-Security"
