Red Team

Seguridad Ofensiva · Pentesting · Explotación

Intermedio-Avanzado

📋 ¿Qué es el Red Team?

El Red Team simula ataques reales contra una organización para identificar vulnerabilidades antes de que los atacantes reales lo hagan. Es como ser un "hacker bueno" con autorización.

🎓 Lo que aprenderás

Reconocimiento OSINT
Escaneo con Nmap
Explotación Web (SQLi, XSS)
Metasploit Framework
Post-Explotación
Movimiento Lateral
Escalada de Privilegios
Ingeniería Social

🛠️ Herramientas Principales

Nmap Burp Suite Metasploit SQLMap Hydra Cobalt Strike

📖 Guía Paso a Paso

1
Reconocimiento

Recopila información sobre el objetivo usando fuentes públicas (OSINT). Usa herramientas como theHarvester, Shodan y Google Dorks.

theharvester -d target.com -b google,bing,linkedin
2
Escaneo y Enumeración

Descubre puertos abiertos, servicios y versiones. Identifica posibles puntos de entrada.

nmap -sV -sC -oA target target.com
3
Explotación

Explota las vulnerabilidades encontradas para obtener acceso al sistema.

msfconsole -x "use exploit/multi/handler; set PAYLOAD python/meterpreter/reverse_tcp; run"
4
Post-Explotación

Mantén el acceso, escala privilegios y mueve lateralmente por la red.

meterpreter > getsystem
meterpreter > hashdump
meterpreter > run persistence

Blue Team

Defensa · SOC · Monitoreo · Respuesta a Incidentes

Intermedio

📋 ¿Qué es el Blue Team?

El Blue Team es responsable de defender la infraestructura de TI contra amenazas. Monitorea sistemas, detecta intrusiones y responde a incidentes de seguridad.

🎓 Lo que aprenderás

Análisis de Logs
SIEM (Wazuh/ELK)
Threat Hunting
Respuesta a Incidentes
Hardening de Sistemas
Configuración de Firewalls
Análisis de Malware
Reportes de Seguridad

🛠️ Herramientas Principales

Wazuh ELK Stack Wireshark OSSEC Snort Volatility

📖 Guía Paso a Paso

1
Configurar SIEM

Instala y configura Wazuh para monitorear tus sistemas.

curl -sO https://packages.wazuh.com/4.7/wazuh-install.sh && sudo bash ./wazuh-install.sh -a
2
Analizar Logs

Aprende a interpretar logs de seguridad para detectar actividades sospechosas.

cat /var/log/auth.log | grep "Failed password" | tail -20
3
Detectar Intrusiones

Usa reglas de detección para identificar patrones de ataque.

# Regla Wazuh para detectar brute force
<rule id="100001" level="10">
<if_sid>5712</if_sid>
<match>Failed password</match>
<description>Brute force detected</description>
</rule>
4
Responder al Incidente

Sigue el proceso de respuesta: Identificar → Contener → Erradicar → Recuperar.

📖 Guía: Analizar tu Primer Malware

1
Preparar Entorno

NUNCA analices malware en tu máquina real. Usa una VM aislada.

# Crear VM en VirtualBox con Ubuntu
# Configurar red: Host-Only (aislada)
# Crear snapshot ANTES de analizar
2
Análisis Estático

Examina el archivo sin ejecutarlo.

# Identificar tipo de archivo
file malware样本.exe

# Extraer strings
strings -n 8 malware样本.exe

# Calcular hashes
sha256sum malware样本.exe
3
Análisis Dinámico

Ejecuta el malware en sandbox y observa su comportamiento.

# Usar Any.Run (online)
# https://app.any.run

# O Cuckoo Sandbox (local)
cuckoo submit malware样本.exe
