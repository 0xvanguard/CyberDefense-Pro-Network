## 🎯 Resumen Ejecutivo
TL;DR en una línea: "Exploté [VULNERABILIDAD] para obtener acceso inicial y escalé privilegios via [TÉCNICA]."

---

## 🔍 Reconocimiento

### Nmap Scan
```bash
nmap -sV -sC -oN nmap.txt TARGET_IP
```
| Puerto | Servicio | Versión |
|--------|----------|---------|
| 22     | SSH      | OpenSSH 8.x |
| 80     | HTTP     | Apache 2.4.x |

### Web Enumeration
```bash
gobuster dir -u http://TARGET_IP -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt
```
- /admin → 200
- /backup → 403
- /uploads → 200

### Hallazgos OSINT
- [ ] Subdominios encontrados
- [ ] Tecnologías identificadas (Wappalyzer)
- [ ] Información expuesta

---

## 💥 Explotación

### Vector de Entrada
- **URL:** http://TARGET_IP/vulnerable-page
- **Parámetro:** id
- **Vulnerabilidad:** SQL Injection

### Payload
```sql
' UNION SELECT username,password FROM users--
```

### Resultado
```
admin:5f4dcc3b5aa765d61d8327deb882cf99
```

### Shell Inicial
```bash
ssh admin@TARGET_IP
# Password: password123
```

---

## 🚀 Escalada de Privilegios

### Enumeración
```bash
# Binarios SUID
find / -perm -4000 2>/dev/null

# Sudo rights
sudo -l
```

### Vector de Privesc
- **Binario vulnerable:** /usr/bin/vulnerable
- **Técnica:** GTFOBins
- **Comando:** `./vulnerable -s`

### Root Shell
```bash
# Whoami
root
```

---

## 🛡️ Lecciones Defensivas

### ¿Cómo se detectaría?
- Wazuh: Alerta de SQL Injection en logs de Apache
- SIEM: Patrón de Login fallidos múltiples

### ¿Qué control hubiera prevenido?
- Input validation en el código
- WAF (ModSecurity)
- Least privilege en SUID binaries

### Indicadores de Compromiso (IOCs)
- IP del atacante
- User-Agents sospechosos
- Archivos creados/modificados

Crea Tu Propio Lab

Aprende a crear entornos vulnerables reproducibles con Docker.

1

Planifica tu escenario

Define qué vulnerabilidad quieres practicar. Ejemplo: SQL Injection en PHP + MySQL.

2

Crea el docker-compose.yml

Define los servicios: web server, base de datos, red aislada.

3

Escribe el código vulnerable

Implementa la aplicación con la vulnerabilidad intencional.

4

Crea la writeup

Documenta pasos, payloads, soluciones y lecciones defensivas.

docker-compose.yml - SQLi Lab
version: '3.8'

services:
  web:
    build: ./web
    ports:
      - "8080:80"
    depends_on:
      - db
    networks:
      - vulnerable-net

  db:
    image: mysql:5.7
    environment:
      MYSQL_ROOT_PASSWORD: root
      MYSQL_DATABASE: vulnerable_app
      MYSQL_USER: app_user
      MYSQL_PASSWORD: app_pass
    volumes:
      - ./db/init.sql:/docker-entrypoint-initdb.d/init.sql
    networks:
      - vulnerable-net

networks:
  vulnerable-net:
    driver: bridge
