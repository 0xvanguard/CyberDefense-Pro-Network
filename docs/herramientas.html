Reconocimiento y Enumeration

Descubre hosts, puertos, servicios y tecnologías del objetivo.

Nmap

Escáner de redes

El escáner de redes y puertos más popular del mundo. Esencial para cualquier pentest.

Ping sweep Port scanning Service detection OS fingerprinting NSE scripts
Comandos Comunes
# Escaneo rápido de puertos comunes
nmap target.com

# Escaneo completo con versiones y scripts
nmap -sV -sC -O -p- target.com

# Escaneo stealth (SYN scan)
nmap -sS -T2 -Pn target.com

# Scripts de vulnerabilidad
nmap --script=vuln -p 80,443,8080 target.com

# Output organizado
nmap -oA resultado target.com
Gratis / Pre-instalado en Kali nmap.org

Gobuster

Directory Bruteforcing

Descubre directorios, archivos y subdominios ocultos en servidores web.

Directory mode DNS mode VHost mode Fuzzing
Comandos Comunes
# Directorios ocultos
gobuster dir -u http://target.com -w /usr/share/wordlists/dirb/common.txt

# Subdominios
gobuster dns -d target.com -w subdomains.txt

# VHosts
gobuster vhost -u http://target.com -w vhosts.txt

# Con extensiones
gobuster dir -u http://target.com -w wordlist.txt -x php,html,txt
Gratis / Go install github.com/OJ/gobuster

Subfinder

Subdomain Discovery

Encuentra subdominios usando múltiples fuentes pasivas (CT, DNS, APIs).

40+ fuentes Rápido Sin interactuar con el target
Comandos
# Básico
subfinder -d target.com

# Con todas las fuentes
subfinder -d target.com -all

# Output a archivo
subfinder -d target.com -o subdomains.txt
Gratis / Go install github.com/projectdiscovery/subfinder

SQLMap

SQL Injection Automation

Automatiza la detección y explotación de inyecciones SQL en aplicaciones web.

Detección automática 6 tipos de inyección Extracción de datos OS shell
SQLMap Commands
# Detección básica
sqlmap -u "http://target.com/page?id=1"

# Extraer bases de datos
sqlmap -u "http://target.com/page?id=1" --dbs

# Extraer tablas
sqlmap -u "http://target.com/page?id=1" -D testdb --tables

# Extraer datos
sqlmap -u "http://target.com/page?id=1" -D testdb -T users --dump

# POST request
sqlmap -u "http://target.com/login" --data="user=admin&pass=*" --batch

# Bypass WAF
sqlmap -u "http://target.com/page?id=1" --tamper=space2comment
Gratis github.com/sqlmapproject/sqlmap

Wireshark

Network Protocol Analyzer

El analizador de protocolos de red más utilizado. Captura y examina tráfico en tiempo real.

2000+ protocolos Real-time capture Deep packet inspection VoIP analysis
Filtros Comunes
# Filtrar por IP
ip.addr == 192.168.1.100

# Filtrar por puerto
tcp.port == 80

# Filtrar por protocolo
http || dns

# SQL injection attempts
http.request.uri contains "SELECT" || http.request.uri contains "UNION"

# DNS queries
dns.qry.name contains "target.com"

# Exportar paquetes
# File → Export Specified Packets

Forense Digital

Análisis de discos, memoria, redes y evidencia digital.

Volatility

Memory Forensics

El framework líder para análisis forense de memoria RAM. Extrae procesos, conexiones, DLLs y más.

Process listing Network connections DLL analysis Registry hives
Volatility Commands
# Identificar imagen
volatility -f memory.dump imageinfo

# Listar procesos
volatility -f memory.dump --profile=Win7SP1x64 pslist

# Procesos con árbol
volatility -f memory.dump --profile=Win7SP1x64 pstree

# Conexiones de red
volatility -f memory.dump --profile=Win7SP1x64 netscan

# DLLs
volatility -f memory.dump --profile=Win7SP1x64 dlllist

# Dump de proceso
volatility -f memory.dump --profile=Win7SP1x64 procdump -p 1234
Gratis / Python github.com/volatilityfoundation/volatility

Análisis de Malware

Reverse engineering, detección y análisis de software malicioso.

YARA

Pattern Matching

El "grep" del malware. Crea reglas para identificar y clasificar muestras de malware.

Pattern matching Binary analysis Rule creation Integration
Regla YARA
rule Malware_Ejemplo {
    meta:
        author = "CDPN"
        description = "Detecta malware de ejemplo"

    strings:
        $s1 = "cmd.exe /c" nocase
        $s2 = "http://c2server.com"
        $s3 = { 6A 00 6A 00 6A 03 6A 00 }

    condition:
        2 of ($s*) and filesize < 500KB
}

# Uso
yara -r rules/ malware_sample.exe
Gratis virustotal.github.io/yara
