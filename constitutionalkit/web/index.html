ℹ️ About ConstitutionalKit

ConstitutionalKit is a comprehensive framework for implementing Constitutional AI safety principles. It provides:

  • 🛡️ 105 constitutional principles across 10 safety categories
  • 🔍 Automated compliance evaluation for LLM prompt/response pairs
  • 📝 Automatic revision engine that generates safe alternative responses
  • 📊 Batch evaluation for testing at scale
  • 📥 JSON export/import for custom constitutions
  • 🧪 38 tests ensuring reliability
